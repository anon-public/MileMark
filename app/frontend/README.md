# Overview
A new way to accomplish task by completing the progress bar, and taking notes along the journey.
Recording the essential details and marking the Mile Marks along the way in the user preferred suitable themes. 

# Features
- CRUD Operations on Notes
- CRUD Operations on Task
- Animations and smooth User Experience
- Live Task Tracking Progress Bar
- Dark/Light Theme Modes
- Search Task or Notes in an instant
  
# Tech Stack
- Frontend: React Native (Expo)
- Database: SQLite 

# Architecture
Mobile (Expo) → SQLite Database → App responds accordingly

# Getting Started
Install the latest version of **MileMark** app from the releases section on your Android or ios platfrom. No need to run the frontend code as for mobile platfrom app.
For Web version need to run the following code in the terminal:
```bash
cd app/frontend
npx expo start --clear

```
